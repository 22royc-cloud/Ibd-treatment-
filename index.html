About

A small set of reference pages for gastroenterology, kept current and deliberately boring to use.

Clinical decision support, not a prescribing authority. Adult patients, elective settings unless stated. Verify against your local protocol and the current label before acting. This page does not replace discussion with cardiology or haematology where the guidelines call for it.
How it is built. Each page is a single HTML file with everything inside it — no database, no tracking, no accounts, no network calls after the page loads. That is why it works in aeroplane mode and why it will still open in ten years.
Add to Home Screen. In Safari, tap Share → Add to Home Screen. It opens full-screen like an app.
